# Scaffold Explainer

Run this once at the start of a new essay so the user can immediately drop sources and start authoring chapters.

## Inputs (collect first)

- **Slug** (kebab-case): e.g. `longevity`. Must be unique under `src/lib/explainers/`.
- **Title**: e.g. "Longevity".
- **Short name**: 1–2 words for the Nav badge, e.g. "LONG".
- **Eyebrow**: editorial category, e.g. "Health & ageing".
- **Tagline**: <80 chars, e.g. "What actually moves the needle on a longer, healthier life."
- **Accent**: `red` | `amber` | `pink` | `ink`.
- **Emoji**: a single representative emoji.
- **Description**: 1–2 sentences for SEO and the explainer card.

If any input is missing, use `AskQuestion` to gather them up front in a single batch.

## Files to create

```
- [ ] src/lib/explainers/<slug>/meta.ts            (filled with the inputs above)
- [ ] src/lib/explainers/<slug>/chapters.ts        (export const chapters: Chapter[] = []; getChapter helper)
- [ ] src/lib/explainers/<slug>/sources.ts         (export sources: Record<string, Source> = {}; getSource helper)
- [ ] src/lib/explainers/<slug>/terms.ts           (export terms: Record<string, Term> = {}; getTerm helper)
- [ ] src/lib/explainers/<slug>/image-manifest.ts  (empty imageManifest: ImageEntry[] = []; auto-regenerated by build-images.mjs)
- [ ] src/lib/explainers/<slug>/index.ts           (ActiveExplainer barrel — mirror ultra-processed/index.ts)
- [ ] src/routes/explainers/<slug>/+page.svelte    (hero + chapters loop + EssayFooter; activateExplainer(...))
- [ ] static/explainers/<slug>/images/.gitkeep
- [ ] static/explainers/<slug>/sources/.gitkeep
- [ ] static/explainers/<slug>/animations/.gitkeep
- [ ] docs/explainers/<slug>/README.md
- [ ] docs/explainers/<slug>/sources/.gitkeep
```

## Files to edit

```
- [ ] src/lib/data/explainers.ts — append an ExplainerSummary entry (default status: 'in-progress')
- [ ] docs/ai/roadmap.md — add an "🔥 Now" entry to drop sources & start authoring
```

## Templates

Use `src/lib/explainers/ultra-processed/*` as the reference shape. Specifically:

- **meta.ts**: copy the shape, swap values from the inputs.
- **index.ts**: identical structure to `ultra-processed/index.ts`, just swap the slug name.
- **chapters.ts / sources.ts / terms.ts**: import the type, export the empty record/array, export the getter helper.
- **+page.svelte**: copy the structure from `src/routes/explainers/ultra-processed/+page.svelte` but render a stub hero plus an empty chapters loop. Always wire `onDestroy(activateExplainer(<slug>))`.

## Workflow

```
- [ ] 1. Collect inputs (AskQuestion if needed)
- [ ] 2. Verify slug doesn't exist
- [ ] 3. Create all files above using the existing ultra-processed/ folder as the reference
- [ ] 4. Append entry to src/lib/data/explainers.ts (status: 'in-progress')
- [ ] 5. Print: "Drop sources into docs/explainers/<slug>/sources/, then run the source-extraction skill."
- [ ] 6. Print: "Add hero images to static/explainers/<slug>/images/, then run the build-images skill."
- [ ] 7. Do NOT run pnpm install / build automatically — the user runs the build step themselves.
```

## Status lifecycle

- `planned` — slug reserved, no chapters yet. Cards on the landing page show "Coming soon".
- `in-progress` — scaffolded, chapters partially written. Cards show "In progress".
- `published` — at least one chapter shipped. Cards become a clickable link.

Default new explainers to `in-progress`.

## After this skill

Hand off to `source-extraction` (drop PDFs first) or `add-chapter` (if facts are already curated).
